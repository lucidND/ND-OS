# ND OS — Branding Guide

## Core identity

- Product name: **ND OS**
- Assistant name: **ND**
- Primary mark: luminous blue “ND” lettering
- Motto: **Smarter • Stronger • Yours**

## Visual direction

The interface should feel modern and purposeful, not crowded or dated.

- Backgrounds: midnight navy and near-black
- Accent: electric blue
- Text: high-contrast white and cool grey
- Effects: restrained blue glow, soft gradients, subtle depth
- Shapes: clean cards, rounded corners, consistent spacing
- Motion: smooth and brief; never distracting

## Interface priorities

1. Make the ND identity recognizable at a glance.
2. Keep the main home screen simple.
3. Make the assistant easy to reach.
4. Keep text large and readable.
5. Put secondary controls in Settings rather than crowding the main screen.
6. Make microphone and listening states obvious.

The glowing “ND” concept is the visual reference for the first prototype. Final logo assets, icon sizes, and color values will be specified after the first interface review.
